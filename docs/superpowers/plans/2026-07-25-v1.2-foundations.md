# RackStack v1.2 — Foundations & Balance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move RackStack to a server-authoritative model with a live-tunable config service, roles, an admin balancing dashboard, custom usernames, and the approved heat/Balance-game retuning — per spec §3 (`docs/superpowers/specs/2026-07-25-rackstack-expansion-design.md`).

**Architecture:** A dependency-free ESM package at repo root `shared/` holds all game data, the config schema/defaults, the rules engine, lazy evaluation, and the action reducer. The server imports it natively and becomes the single source of truth (canonical state in the `saves` table, advanced lazily — no game loop); the client imports it via a Vite alias and uses it only for optimistic prediction, dispatching typed actions to `POST /api/actions`.

**Tech Stack:** Node 20 ESM, Express 4, better-sqlite3, React 18 + Vite 5, vitest + supertest (new dev deps, repo root).

## Global Constraints

- `shared/` modules: pure ESM, **zero runtime dependencies**, no React/lucide/node-API imports (must run in browser and Node).
- All role/permission checks happen **server-side per request**; client role constants only gate UI visibility (spec §8).
- Existing v1.1 saves must load without loss (spec §3.3 Migration). Fixture test required.
- DB changes are additive: `CREATE TABLE IF NOT EXISTS` + guarded `ALTER TABLE` (spec §7).
- Super admins come from env var `SUPER_ADMIN_IDS` (comma-separated), not hardcoded (spec §3.4).
- Config defaults (spec §3.6): heat capacity **2000**, vent **500**, Balance scoring **+1 safe / +5 risk strips (4% each, inside safe-zone edges) / −2 miss, floor 0**.
- Usernames: 3–20 chars matching `^[A-Za-z0-9_-]+$`, case-insensitive-unique in DB (spec §3.7).
- Tier/grid/overclock cost & production **curves stay in code** — not tunable (spec §3.1).

```js
  schemaVersion: 1,
  heat: { capacity: 2000, ventAmount: 500, ventCooldownMs: 2500, overheatCooldownMs: 10000 },
  minigames: {
    winCooldownMs: 30000,
    rush:  { durationSec: 10, waferDivisor: 4, maxTapsPerSec: 15 },
    debug: { durationSec: 15, spawnMinMs: 400, spawnMaxMs: 900, maxLit: 3, waferDivisor: 2 },
    match: { durationSec: 40, pairCount: 10, waferPerPair: 2 },
    balance: { durationSec: 12, safeZoneMin: 35, safeZoneMax: 65, riskZoneWidth: 4,
               pointsSafe: 1, pointsRisk: 5, missPenalty: 2, maxScore: 150 },
  },
  production: { globalMult: 1, racksMult: 1, gridMult: 1, overclockMult: 1 },
  offline: { baseCapHours: 4, capPerUptimeLevel: 1, hardCapHours: 72, onlineGapThresholdSec: 60 },
  anomaly: { windowMs: 15000, minDelayMs: 70000, maxDelayMs: 150000 },
  upgrades: { maxLevels: {
    firmware: 20, psu: 10, uptime: 8, signal: 10, gridamp: 15, legacy: 10,
    thermal: 8, autovent: 8, occlock: 15, lucky: 10, deepcache: 10,
    bootstrap: 5, temporal: 5, engine: 8, heatsink: 4, infiniteloop: 5, echocores: 10,
  } },
};

export const TUNABLES = [
  { path: 'heat.capacity', label: 'Heat capacity', min: 100, max: 100000, integer: true },
  { path: 'heat.ventAmount', label: 'Vent amount', min: 1, max: 100000, integer: true },
  { path: 'heat.ventCooldownMs', label: 'Vent cooldown (ms)', min: 0, max: 60000, integer: true },
  { path: 'heat.overheatCooldownMs', label: 'Overheat lockout (ms)', min: 0, max: 600000, integer: true },
  { path: 'minigames.winCooldownMs', label: 'Minigame win cooldown (ms)', min: 0, max: 3600000, integer: true },
  // ... one row per numeric leaf above (rush/debug/match/balance, production 0.1–100,
  //     offline hours 1–168, gap threshold 10–600, anomaly timings) and one row per
  //     upgrades.maxLevels.<id> (min 1, max 99). Every numeric leaf in DEFAULT_CONFIG
  //     except schemaVersion MUST have exactly one TUNABLES row — the test enforces
  //     resolution; validateConfig enforces completeness.
];

export function getAtPath(obj, path) {
  return path.split('.').reduce((o, k) => (o == null ? undefined : o[k]), obj);
}
export function setAtPath(obj, path, value) {
  const keys = path.split('.');
  const last = keys.pop();
  let cur = obj;
  for (const k of keys) { if (typeof cur[k] !== 'object' || cur[k] === null) cur[k] = {}; cur = cur[k]; }
  cur[last] = value;
}

function collectLeafPaths(obj, prefix = '') {
  const out = [];
  for (const [k, v] of Object.entries(obj)) {
    const p = prefix ? `${prefix}.${k}` : k;
    if (typeof v === 'object' && v !== null) out.push(...collectLeafPaths(v, p));
    else out.push(p);
  }
  return out;
}

export function validateConfig(doc) {
  const errors = [];
  if (!doc || typeof doc !== 'object') return { ok: false, errors: ['not an object'] };
  const allowed = new Set(['schemaVersion', ...TUNABLES.map((t) => t.path)]);
  for (const p of collectLeafPaths(doc)) {
    if (!allowed.has(p)) errors.push(`unknown key: ${p}`);
  }
  for (const t of TUNABLES) {
    const v = getAtPath(doc, t.path);
    if (typeof v !== 'number' || Number.isNaN(v)) { errors.push(`${t.path}: missing or not a number`); continue; }
    if (v < t.min || v > t.max) errors.push(`${t.path}: ${v} outside [${t.min}, ${t.max}]`);
    if (t.integer && !Number.isInteger(v)) errors.push(`${t.path}: must be an integer`);
  }
  return errors.length ? { ok: false, errors } : { ok: true };
}

export function upgradeConfig(doc) {
  const out = structuredClone(DEFAULT_CONFIG);
  for (const t of TUNABLES) {
    const v = getAtPath(doc || {}, t.path);
    if (typeof v === 'number' && !Number.isNaN(v)) setAtPath(out, t.path, v);
  }
  return out;
}
```

Port every function listed in Interfaces from `client/src/game/helpers.js` verbatim, then add the config parameter where specified. New functions in full:

```js
import { MILESTONES } from './gameData.js';

export function computeMults(meta, config, boostMult = 1) {
  const eff = computeEffects(meta, config);
  const thresholds = MILESTONES.map((t) => Math.max(1, Math.round(t * eff.milestoneDiscount)));
  const base = (1 + (meta.legacyCores || 0) * 0.05) * eff.firmwareMult * eff.engineMult
    * eff.levelBonusMult * boostMult * config.production.globalMult;
  return {
    eff,
    thresholds,
    racksMult: base * config.production.racksMult,
    gridMult: base * eff.gridExtraMult * config.production.gridMult,
    overclockMult: base * eff.overclockExtraMult * config.production.overclockMult,
  };
}

export function minigameWafers(game, metric, meta, config) {
  const lucky = computeEffects(meta, config).luckyMinigameMult;
  const mg = config.minigames;
  if (game === 'rush') return Math.max(1, Math.floor((metric / mg.rush.waferDivisor) * lucky));
  if (game === 'debug') return Math.max(1, Math.floor((metric / mg.debug.waferDivisor) * lucky));
  if (game === 'match') return Math.floor(metric * mg.match.waferPerPair * lucky);
  if (game === 'balance') return Math.max(1, Math.floor(metric * 1.5 * lucky));
  throw new Error(`unknown game: ${game}`);
}
```

`computeEffects(meta, config)` is the v1.1 body with one change:
`offlineCapHours: config.offline.baseCapHours + config.offline.capPerUptimeLevel * (lv.uptime || 0)`.

**Interfaces:**
- Consumes: Tasks 1–3.
- Produces:
  - `initialState()` -> canonical `{ run, meta, server }`:
    - `run`: `{ credits: 10, lifetimeRun: 0, tiers[14] {id, owned, manager, ready}, grid[5] {id, owned}, overclock[5] {id, owned}, heat: 0, heatCooldownUntil: null }`
    - `meta`: v1.1 meta + `stats.lifetimeFlopsAllTime: 0`
    - `server`: `{ nextAnomalyAt: 0, anomalyExpiresAt: 0, boost: null, lastVentAt: 0, gameCooldowns: { rush: 0, debug: 0, match: 0, balance: 0 } }`
  - `migrateSave(raw)` -> canonical state — accepts a v1.1 `{run, meta}` JSON (no `server` block, possibly short `tiers`, missing stats keys) and returns a padded canonical state; idempotent on already-canonical input.
  - `evaluate(state, config, lastEvaluatedAt, now)` -> `{ state, gained }` — the lazy advance:
    - `elapsedSec = max(0, (now - lastEvaluatedAt)/1000)`; if `< 1` return unchanged, `gained: 0`.
    - **Online gap** (`elapsedSec <= config.offline.onlineGapThresholdSec`): full production for all three lanes via `computeMults` (boost from `server.boost` if `now < boost.until`), heat advances (`heatGain × heatDiscount − autoVent`) unless `heatCooldownUntil` active; crossing `config.heat.capacity` sets `heat = 0`, `heatCooldownUntil = now + config.heat.overheatCooldownMs`, `state.server.overheated = true` flag for the client toast (cleared on next evaluate).
    - **Offline gap**: production capped at `min(eff.offlineCapHours, config.offline.hardCapHours) * 3600` seconds (v1.1 `applyOfflineProgress` semantics: unmanaged tiers accrue into `ready`, managed + grid + overclock into credits); **heat untouched**; expired `heatCooldownUntil` cleared.
    - Both paths: `lifetimeRun` and `stats.lifetimeFlopsAllTime` increase by total produced; expired boost cleared; `gained` = total produced (offline path only, else 0 — powers the welcome-back modal).
